# Paradise Nursery

Paradise Nursery is a React and Redux houseplant shopping application created for the IBM Developing Front-End Apps with React final project.

## Features

- Landing page with company information and a Get Started button.
- 18 houseplants organized into three categories.
- Add-to-cart functionality with a disabled button after a plant is added.
- Dynamic cart quantity in the navigation bar.
- Shopping cart with thumbnails, names, unit prices, quantities, item totals, and overall totals.
- Increase, decrease, and delete cart controls.
- Continue Shopping navigation.
- Checkout button with a Coming Soon message.
- Responsive desktop and mobile layout.

## Technologies

React, Redux Toolkit, React Redux, JavaScript, CSS, Vite, and GitHub Pages.
